# AAROH Clothing E-commerce

A responsive premium-minimal storefront for AAROH — **Wear Your Rise.**

## Included
- Responsive storefront
- AAROH brand system: charcoal, sand, ivory, olive, antique gold
- Hero, manifesto, story and journal sections
- Product filtering
- Functional local-storage shopping bag
- Mobile navigation
- Newsletter interaction
- Product imagery from the supplied AAROH brand references

## Run locally

No build step is required.

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.
